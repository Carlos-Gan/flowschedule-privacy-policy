Política de Privacidad de FlowSchedule

Fecha de entrada en vigor: 21 de septiembre de 2026

Charlie Moran ("nosotros" o "nuestro") opera la aplicación móvil FlowSchedule. Esta página le informa sobre nuestras políticas con respecto a la recopilación, uso y divulgación de datos personales cuando utiliza nuestra aplicación.

1. Recopilación y uso de información
FlowSchedule es una aplicación de gestión de horarios y tareas diseñada para funcionar de forma local en su dispositivo. No recopilamos, almacenamos ni transmitimos ningún tipo de información personal, identificadores de dispositivo, datos de ubicación ni contenido creado por el usuario a servidores externos ni a terceros.

2. Almacenamiento local de datos
Todos los datos ingresados en la aplicación (tales como horarios, materias, tareas y recordatorios) se guardan exclusivamente en el almacenamiento interno de su dispositivo mediante bases de datos locales. Usted tiene el control total sobre esta información y puede eliminarla en cualquier momento borrando los datos de la aplicación o desinstalándola.

3. Servicios de terceros
La aplicación no utiliza servicios de terceros que puedan recopilar información utilizada para identificarlo.

4. Cambios a esta política de privacidad
Podemos actualizar nuestra Política de Privacidad de vez en cuando. Se le notificará de cualquier cambio publicando la nueva Política de Privacidad en esta página.

5. Contacto
Si tiene alguna pregunta o sugerencia sobre nuestra Política de Privacidad, no dude en contactarnos a través de nuestro correo de soporte técnico registrado en la tienda.
